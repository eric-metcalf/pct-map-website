# Content Management

This directory contains markdown files that control the content displayed on the website.

## Files

### `home.md`
Controls the content displayed on the home page (index.html).

## How to Update Content

### Updating the Home Page

1. Open `content/home.md` in any text editor
2. Edit the content using Markdown syntax
3. Save the file
4. Refresh the home page in your browser to see changes

## Markdown Syntax Guide

### Headers
```markdown
# Main Title (H1)
## Section Title (H2)
### Subsection Title (H3)
```

### Text Formatting
```markdown
**Bold text**
*Italic text*
```

### Links
```markdown
[Link Text](url)
```

### Lists
```markdown
- Bullet point 1
- Bullet point 2

1. Numbered item 1
2. Numbered item 2
```

### Horizontal Line
```markdown
---
```

### Paragraphs
Just write text with blank lines between paragraphs.

## Example Content Structure

```markdown
# Welcome Title

Introduction paragraph with **bold** and *italic* text.

## Section 1

Content for section 1.

### Subsection 1.1
Details about subsection.

[Link to Page](page.html)

---

## Section 2

- Point 1
- Point 2
- Point 3
```

## Tips

- Keep content concise and readable
- Use headers to organize content hierarchically
- Add horizontal lines (`---`) to separate major sections
- Use links to connect to other pages (map.html, photography.html)
- Preview changes by refreshing the browser
